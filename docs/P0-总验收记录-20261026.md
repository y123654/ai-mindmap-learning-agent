## 四、过程问题与纠错（如实记录）

1. **识别器两次过拟合被组长复跑抓到**：v1「未执行该指令」误判、v2「笔记里没有写」误判；v3 冻结后 final 0 条误拒。
2. **并发评测互踩**：12:30 组长与子 agent 同时跑评测，互相清理评测用户；A2 加 PG advisory lock 后，第二次并发 23s 内被拒。
3. **并发构建假阳性**：组长 22:17 的 845 跑出现 2 个 `Not a managed type`，与子 agent 的 Maven 同时写 `target/classes` 有关；单独重跑 845 全绿。
4. **方案三处缺口**（已在方案文档增量修订）：`app.ai.api-key` 漏列、`cleanupJdbc` 绕开 config、`agent_evidence.resource_id` 类型；后者经所有者批准改 VARCHAR(64)。
5. **命令引号坑**：`-Deval.report.name=...` 不加引号被 PowerShell 拆段，两次 0.5s 失败、零费用；已修正。
