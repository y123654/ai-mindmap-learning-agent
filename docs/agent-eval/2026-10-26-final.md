## 7. 拒答识别器 v3 规格与局限（2026-10-26 冻结）

> **冻结声明**：v3 定稿后，50 条基线运行期间不再改识别器。若基线里出现新的误判，只把回答与识别依据记录在本节并标注「识别器局限」，**不允许改规则凑分**；根治靠 P0-C 的 LLM Judge。

**为什么有 v3**：v1 把「未执行该指令，只把它当作笔记」判成拒答（模型在汇报「我忽略了注入」）；v2 把「笔记里**没有写**，实验数据、甘特图、对比结论都缺失」判成误拒（smoke-010）。两次都是组长独立复跑抓到，所以 v3 只认两类信号、并加两层排除。

**v3 判定规则**（实现在 `EvalMetrics.checkRefusal`）：

| 步骤 | 规则 |
|---|---|
| ① 切句 | 按 `。` `；` 换行 切句，只评估**起始位置在前 300 字以内**的句子 |
| ② 强拒答短语 | 没有找到/未找到/暂无/没有相关/未检索到/找不到/无法回答/不能回答/没有讲/没有提到/没有涉及/没有提及/并未提及/均无 |
| ③ 受限句式 | 材料类名词（笔记/资料/内容/记录/检索/题库/导图/记忆）在 12 字以内出现「没有」或「未」 |
| ④ 安全声明排除 | 同句含 指令/注入/系统提示/忽略/未执行/越权 → 不判拒答，只记 `skip(安全声明=…)` |
| ⑤ 材料缺部分排除 | 同句含 缺失/缺少/没有写/没有给出 → 不判拒答，只记 `skip(材料缺部分=…)` |
| ⑥ 疑问式排除 | 拒答词/否定词紧跟「有」（有没有…）是疑问句不是否定，不算拒答 |

**本次观测到的识别器风险（只记录，不改规则）**：

- 误拒（不该拒答却识别为拒答）：0 条。
- 漏拒（应拒答但没识别）：0 条。

其余已知局限：① 「根据笔记内容，FCFS 没有抢占」这种材料词与「没有」恰好靠近、但语义不是拒答的句子仍可能被误判；② 真拒答句同时含「没有写」会被材料缺部分规则放过；③ 强拒答短语不要求材料词，正文出现「暂无」「均无」等也可能被算拒答。这些都不在基线运行期间修，写进报告作为「识别器局限」。
